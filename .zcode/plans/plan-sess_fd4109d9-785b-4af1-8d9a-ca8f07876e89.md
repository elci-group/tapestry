# Gate 0 — Scaffold `tapestry-core`

## Context
The Tapestry directive's Gate 0 (Foundations) requires `tapestry-core` to exist with identity, session/artefact/review schemas, and a TAP protocol skeleton before any client work. Swarm A owns it and delivers first; all other swarms will consume these versioned contracts. The user confirmed scope: **tapestry-core only**, in the empty `/home/sal/tapestry` workspace.

## Ecosystem conventions to follow (from boar/ami/lwoodz survey)
- Standalone crate: `lib.rs` + thin `main.rs` (or lib-only), `tests/*.rs` integration tests
- Top-level: `VERSION`, `README.md`, `poka.toml`, `kaptaind.toml`, `deliver.toml`, `LICENSE`
- Errors: `thiserror` for the library, deps `serde`/`serde_json`, `sha2`+`hex` for content addressing, `chrono` or std time, `uuid` or ULID-style ids (implement small ULID-like id to keep deps lean; prefer `uuid` v4 feature)
- `edition = "2021"`, `[profile.release] lto = "thin"`, `strip = true`
- Optional `form3 = { path = "../3form" }` for shared pretty-printing (only if it fits; skip if it drags in surface we don't need)

## Repository layout — `/home/sal/tapestry/tapestry-core/`

```text
tapestry-core/
├── Cargo.toml            # name tapestry-core, version 0.1.0, lib only
├── VERSION               # 0.1.0
├── README.md             # purpose, module map, Gate 0 status
├── LICENSE
├── poka.toml             # [project], tools, rules — copy shape from boar/poka.toml
├── kaptaind.toml         # watch/cluster/weights/test gate — copy shape from boar/kaptaind.toml
├── deliver.toml          # [[file]] + [[command]] gates: cargo test/clippy/fmt --check
└── src/
    ├── lib.rs            # module decls, crate-level docs, TapestryError
    ├── ids.rs            # SessionId, ArtifactId, DeviceId, ReviewId: typed newtypes, ULID-sortable ids
    ├── identity.rs       # DeviceIdentity, CapabilitySet (display/audio/input/storage/codecs), TAP version
    ├── session.rs        # Session, SessionState, SessionEvent (state-machine transitions)
    ├── artifact.rs       # Artifact envelope (§19: id, session_id, revision, kind, mime, uri,
    │                     #   digest, byte_length, dimensions, duration, codec, producer,
    │                     #   provenance, created_at, comparison_group, inspection_hints),
    │                     #   ArtifactKind enum (IMAGE..COMPOSITE), content-addressed digest helper
    ├── review.rs         # ReviewDecision (§25: APPROVE/REJECT/SELECT/COMPARE/ANNOTATE/
    │                     #   REQUEST_VARIATION/DEFER), ReviewRecord
    ├── telemetry.rs      # correlation hierarchy ids (programme/session/drive/task/operation),
    │                     #   TimingEvent names from §30
    ├── capability.rs     # media/codec capability descriptors + H.265 negotiation helper
    │                     #   (returns required codec only after explicit probing — §18/§40)
    └── protocol/
        ├── mod.rs        # TAP/1 constants, ProtocolVersion
        ├── frame.rs      # TAP frame: session, channel (CONTROL/EVENT/ARTEFACT/TELEMETRY/
        │                 #   REVIEW/MEDIA), type, seq, artifact, offset, len, digest (§9)
        ├── chunk.rs      # resumable chunk bookkeeping: offset/len/digest, ack/replay types
        └── negotiate.rs  # capability negotiation message types
```

Key design points:
- All types `serde::{Serialize, Deserialize}` with `#[serde(deny_unknown_fields)]` where sensible — these are wire contracts.
- Deterministic ids: time-sortable ULID-style (Crockford base32) implemented in `ids.rs` with round-trip tests, so journal replay stays stable.
- Digest = sha256 hex, helper `artifact::content_digest(bytes)` producing `sha256/<digest>` keys (§32).
- Review decisions and session events are plain data (no IO, no tokio) — Gate 0 is contracts only. Transport IO (channels, crypto, reconnect) is Swarm D / later gates.
- No `form3` dependency unless needed; keep deps: serde, serde_json, thiserror, sha2, hex, uuid, chrono(serde), semver.

## Tests (evidence, not self-report)
- `tests/schema_roundtrip.rs` — serde JSON round-trip for every public contract type; deny_unknown_fields rejects stray fields
- `tests/frame_roundtrip.rs` — TAP frame encode→decode→encode byte-stability; chunk offset/digest validation; monotonic seq enforcement
- `tests/capability_negotiation.rs` — codec selection refuses H.265 when unprobed; falls back to H.264
- `tests/session_state.rs` — legal/illegal session transitions, review decision round-trip
- Unit tests in `ids.rs` (sortability, uniqueness) and `artifact.rs` (digest stability)
