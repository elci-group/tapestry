# tapestry

Distributed presentation and human-inspection harness: a television becomes
a network-addressable perceptual terminal, never an agent workstation.

- `tapestry-core` — versioned contracts: identity, sessions, artefacts,
  reviews, telemetry and the TAP/1 protocol schema (Gate 0).
- `tapestry-desktop` — the `tapestry` CLI and desktop coordination plane:
  scoped credentials, Playbook drive adapter, Mesut lanes, knowledge
  journal, loopback TAP transport, share tokens, temperature policy
  (Gates 1–8 desktop plane).

```sh
tapestry "Generate four visual concepts for the Tapestry home screen"
```

See each crate's README for module maps and gate status.
